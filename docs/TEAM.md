# Как делить работу

Репозиторий специально плоский: один сервис, понятные пакеты, YAML вместо магических констант.

## По ролям

| Кто | Где жить | Критерий «готово» |
|---|---|---|
| Бэкенд / загрузка | `ingest`, `service/DatasetService` | Файл до 3 ГБ принимается потоком, описание API на `/api.html` |
| Трассировка | `engine.flow` | Трассы конкурсного набора, обход зданий, выход ИТП по нормали к фасаду |
| Расчёт DN и деньги | `costing`, `config/appendix.yml` | Цифры совпадают с приложением от 26.09.2026, реконструкция в смету не входит |
| Карта и демо | `static/` | Сценарий из `docs/DEMO.md` проходит без консоли |
| Глубина | `engine.depth` | Режим DEPTH пишет `depth_start` и `depth_end`, Kгл по разделу 5 |
| Документация и питч | `docs/`, `docs/pitch/` | 10 пунктов демонстрации закрыты |

## Правила, чтобы не мешать друг другу

1. Не коммитьте конкурсный GeoJSON и каталог `data/`.
2. Новые магические числа — только в YAML.
3. Новый алгоритм — новый класс + один `@Primary` / профильный бин, API не трогаем.
4. Перед пушем: `./mvnw test`.
5. Ветки: `feat/routing-grid`, `feat/cost-tables`, `feat/ui-layers` и т.п.
