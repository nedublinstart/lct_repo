# Сценарий демонстрации (пункты ТЗ §4)

1. Открыть http://localhost:8080 → «Демо на мини-наборе» или загрузить конкурсный GeoJSON.
2. Дождаться статуса `PARSED`, нажать «Построить варианты». Ручной правки геометрии нет.
3. «Скачать GeoJSON варианта» — файл для экспертов.
4. На карте: существующая сеть, новая нитка, точки подключения, врезки, DN/расход в попапе, участки реконструкции.
5. Сквер и дом обходятся, дорога пересекается (слой ограничений).
6. Попап `reconstruction_segment`: extra_flow, existing_dn → required_dn.
7. Если ОКС не собрался — карточка варианта показывает список id (и фича `unconnected_oks`).
8. Три карточки вариантов, score = 70% стоимость + 30% длина. Переключение слоёв без пересчёта.
9. Алгоритм — `docs/ALGORITHM.md`. Границы — §2.12 ТЗ, не обещаем гидравлику.
10. Режим «С учётом глубины» — отдельный job `DEPTH`.

Запасной канал, если UI спорит с проектором: Swagger `/swagger-ui.html`.
