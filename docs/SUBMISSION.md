# Сдача

## Промежуточная / текущее состояние

- Каркас Java 11 + Spring Boot 2.6.3 + springdoc 1.7.0 + docker-compose 2.4.
- Потоковая загрузка GeoJSON, PostgreSQL/H2, карта. Перед расчётом выбираются режимы; «Минимальная стоимость» — трасса с наименьшей полной ценой. Вариант хуже других и по цене, и по врезкам, и по реконструкции не отдаётся.
- Официальное техническое приложение в `config/appendix.yml`.
- Конкурсный набор `!!!_Датасет.geojson` разбирается и считается движком леса минимальной стоимости (`engine.flow`: граф видимости, DN по расходу, камеры, врезки, частичная реконструкция, рейтинг 70/30).
- Выгрузка сдачи: `GET /api/v1/jobs/{id}/result.geojson` и `samples/contest-result.geojson`.
