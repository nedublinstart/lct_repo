# Сдача

## Промежуточная

Сделано в этом репозитории:

- Каркас Java 11 + Spring Boot 2.6.3 + springdoc 1.7.0 + docker-compose 2.4.
- Потоковая загрузка GeoJSON, PostgreSQL/H2, карта, три автоварианта на мини-наборе.
- Расход → DN → реконструкция по `next_id` → стоимость и рейтинг.
- Техническое приложение вынесено в YAML.

Риски:

- Официальные имена атрибутов и таблицы стоимости ещё плейсхолдер.
- Сетка A* на большом районе может быть грубой или медленной — нужен адаптивный граф.
- Самопересечения новой сети в раздельном варианте пока не сливаются в узел.
- 3 ГБ нужно прогнать на боевом файле, не только на мини-наборе.

План до финала:

1. Вписать официальное приложение в YAML, прогнать конкурсный набор.
2. Улучшить трассировку (видимость, запрет лесенки, merge пересечений).
3. Дожать глубину, если останется время.
4. Зафиксировать скрипт демо и 1–2 слайда «как думает алгоритм».
