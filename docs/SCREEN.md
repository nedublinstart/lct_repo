# Справка экрана

Та же справка открывается кнопкой **«Справка»** (`http://localhost:8080`).

## Экран

Слева колонка, справа карта.

| Место | Что делает |
|---|---|
| Шапка | «Теплотрасса». «Справка» открывает этот лист. «Описание API» — перечень методов. «Таблицы DN» — YAML диаметров. |
| Данные | GeoJSON уходит на сервер сразу после выбора. Строка под рамкой зелёная, когда файл разобран. |
| Расчёт | Режимы: минимальная стоимость, минимум врезок, короче трасса. Глубина: план или Z. «Рассчитать» считает отмеченное. Полоска под кнопкой — прогресс. |
| Варианты | До расчёта здесь одна строка. После — карточки. Щелчок меняет трассу. Выгрузка — под списком. |
| Слои | Исходные данные, новая сеть, камеры и узлы. Слои меняют видимость уже посчитанного. |
| Карта | Подложка — космический снимок. Подпись слева внизу: © Esri, Maxar, Earthstar Geographics. Масштаб: «Крупнее» и «Мельче». Знаки справа внизу, «Свернуть» прячет список. Щелчок по объекту открывает карточку. |

Справку закрывают кнопкой «Закрыть», щелчком по затемнению или клавишей Escape.

## Знаки

| Знак | Что значит |
|---|---|
| Существующая сеть | Серая линия. |
| Новая сеть | Сплошная линия. Толщина по DN. |
| Спецпроход | Пунктир. Один прямой отрезок на пересечении. |
| Камера | Тёмно-синий кружок, существующая камера. |
| Новая камера | Тёмно-красный кружок. Стоимость по DN: 3 / 5 / 8 / 12 млн ₽. В выгрузке тип `heat_chamber`. |
| Узел | Мелкая точка, стык участков. |
| Источник | Крупный тёмный кружок. |
| ИТП | Бирюзовый кружок. |
| Здание | Бежевый контур. |
| Вода | Голубая заливка. |
| Железная дорога | Серая заливка. Пересечение запрещено, отступ 1 м. |
| Дорога | Светло-серая заливка, если полигон есть во входном файле. |

## Карточка объекта

Заголовок — тип: «Новая труба», «Новая камера», «Технический узел», «Камера», «Источник», «ИТП», «Здание». Поля подписаны по-русски.

- **Труба.** Идентификатор, вариант, начало, конец, расход т/ч, DN мм, длина м, прокладка («Обычная» или «Спецпроход»), стоимость. В режиме «С глубиной» ещё глубина начала и конца.
- **Новая камера.** Идентификатор, вариант, DN, стоимость.
- **Узел, камера, ИТП, источник, здание.** Идентификатор. Название или адрес — если они есть во входном файле.

## Трасса

1. Выход из ИТП — прямой отрезок по нормали к ближайшему фасаду, до точки сразу за контуром.
2. Дальше прямые вне зданий. Поворот остаётся, если хорда пересекает корпус. Угол поворота до 90° включительно.
3. Спецпроход — один прямой отрезок на реальном пересечении. На карте он пунктирный.

## Карточка варианта

Ранг 1 — наименьший S.

| Поле | Смысл |
|---|---|
| C | Трубы + новые камеры + врезки в существующие камеры + штраф за неподключение. Штраф: 100 млн ₽ + 0,5 млн ₽·т/ч на каждый неподключенный ОКС. |
| L | Длина новой сети, м. |
| S | 0,7·C / 25 000 000 + 0,3·L / 100. Три знака. Меньше — выше в списке. |
| Трубы, камеры, врезки в сущ. | Слагаемые C. Врезка в существующую камеру — 5 000 000 ₽ за каждый новый участок, который в ней заканчивается. Новая камера уже включает присоединение. Штраф показывается, когда он ненулевой. |
| Строка внизу | «Все ОКС подключены» или идентификаторы, которые до сети не дошли. |

Режимы: «Минимальная стоимость» — наименьший S. «Минимум врезок» — в цели поиска врезка сверх первой добавляет 50 млн ₽. «Короче трасса» — вес длины в цели поиска удвоен.
