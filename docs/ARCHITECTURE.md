# Архитектура

Монолит Spring Boot 2.6.3 / Java 11.

```
браузер  →  static UI (Leaflet, подложка OpenStreetMap)
описание API  →  /api.html и REST /api/v1
             ├─ DatasetService      потоковая загрузка GeoJSON на диск + разбор
             ├─ SceneAssembler      свойства → домен (алиасы из YAML)
             ├─ FlowRoutingEngine   текущий расчёт, до трёх вариантов
             ├─ costing             DN, камеры, врезки, Kгл, рейтинг
             ├─ DepthPostProcessor  профиль DEPTH после плана
             └─ ResultGeoJsonExporter
                    ↓
            PostgreSQL / H2     метаданные наборов и задач
            ./data              исходники и результаты на диске
```

Пакеты `engine.greedy` и `engine.steiner` в расчёте не участвуют.

## Как устроен запуск

- Долгий расчёт идёт в пуле `heatnetExecutor` (2–4 потока). HTTP не ждёт окончания, интерфейс опрашивает `/api/v1/jobs/{id}`.
- Файл до 3 ГБ читается потоком Jackson. Объекты пишутся в базу пачками по 400, геометрия хранится текстом. Сам поиск держит собранную сцену в памяти.
- Таблицы DN, Kспец, горизонтальные расстояния, камеры, штраф и формула S лежат в `config/appendix.yml` и перечитываются перед каждым расчётом.
- Правило камеры 10 м, смежность не больше 4 и вертикальные просветы раздела 5 заданы в коде расчёта по приложению.
- Профиль `local` поднимает H2, Docker для разработки не нужен. Профиль `prod` — PostgreSQL 16.
