# Питч

Сюда можно положить PDF презентации. Сценарий живого демо: [`../DEMO.md`](../DEMO.md).

Короткий каркас слайдов:

1. Задача: много ОКС, много врезок, руками не перебрать.
2. Вход: один GeoJSON + YAML-приложение.
3. Как ищем трассу: обход корпусов, граф видимости, лес минимальной полной стоимости. Без сетки A*.
4. До трёх вариантов и рейтинг 70/30. Реконструкция существующей сети не считается.
5. Врезка только в существующую камеру: 5 млн ₽ за новый участок. Новая камера уже включает присоединение.
6. Что не обещаем: гидравлику. Режим «С глубиной» — отдельный запуск, отметки `depth_start` и `depth_end`.
7. Демо на карте.
