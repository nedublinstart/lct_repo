# Питч

Сюда можно положить PDF презентации. Сценарий живого демо: [`../DEMO.md`](../DEMO.md).

Короткий каркас слайдов:

1. Задача: много ОКС, много врезок, руками не перебрать.
2. Вход: один GeoJSON + YAML-приложение.
3. Как ищем трассу: сетка + A* + MST для совместного подключения.
4. Три варианта и рейтинг 70/30.
5. Реконструкция существующей сети по `next_id`.
6. Что не делаем (гидравлика, ИТП, надземка).
7. Демо на карте.
