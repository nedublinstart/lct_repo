API

Карта Таблицы DN

Базовый префикс /api/v1. Тело ошибок: error и details, оба на русском. Машиночитаемая схема: /v3/api-docs.

Наборы

МетодПутьСмысл
POST/datasetsЗагрузка. Поле формы file, GeoJSON, до 3 ГБ.
GET/datasetsСписок наборов.
GET/datasets/{id}Состояние набора и число объектов.
GET/datasets/{id}/preview.geojsonПредпросмотр для карты.
GET/datasets/{id}/featuresСтраница объектов. Параметры kind, limit, offset.

Поле status набора: UPLOADED — принят, PARSING — разбор, PARSED — разобран, FAILED — ошибка разбора.

Расчёт

МетодПутьСмысл
POST/jobsСтарт. JSON: datasetId, mode (PLAN_2D или DEPTH), strategies (mincost, mintaps, minrecon). Пустой список режимов — все три.
GET/jobs/{id}Прогресс, сообщение, ошибка.
GET/jobs/{id}/variantsКарточки вариантов.
GET/jobs/{id}/variants/{rank}Одна карточка. rank с 1.
GET/jobs/{id}/variants/{rank}/geojsonGeoJSON одного варианта.
GET/jobs/{id}/result.geojsonВсе варианты, файл сдачи.

Поле status задачи: QUEUED — в очереди, RUNNING — считаю, COMPLETED — готово, FAILED — ошибка.
