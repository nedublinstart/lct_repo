API

Карта Таблицы DN

Базовый префикс /api/v1. Тело ошибок: error и details, оба на русском. Машиночитаемый перечень методов: /v3/api-docs. Поля и состав выгрузки описаны на этой странице.

Наборы

МетодПутьСмысл
POST/datasetsЗагрузка. Поле формы file, GeoJSON, до 3 ГБ. Ответ приходит сразу, разбор идёт дальше.
GET/datasetsСписок наборов.
GET/datasets/{id}Состояние набора и число объектов.
GET/datasets/{id}/preview.geojsonПредпросмотр для карты, WGS 84.
GET/datasets/{id}/featuresСтраница объектов. Параметры kind, limit (по умолчанию 2000), offset.

status набора: UPLOADED — принят, PARSING — разбор, PARSED — разобран, FAILED — ошибка разбора. Поля ответа: id, originalFilename, status, sizeBytes, featureCount, kindCounts, message, createdAt, updatedAt.

kind: EXISTING_SEGMENT, CHAMBER, SOURCE, OKS_PROSPECTIVE, OKS_EXISTING, CONNECTION_POINT, CONSTRAINT, UNKNOWN. Ответ: total и items. С параметром kind total считает только этот вид.

Расчёт

МетодПутьСмысл
POST/jobsСтарт. Тело JSON ниже. Набор должен быть в состоянии PARSED.
GET/jobs/{id}Прогресс, сообщение, ошибка.
GET/jobs/{id}/variantsКарточки вариантов, без сводного ранга 0.
GET/jobs/{id}/variants/{rank}Одна карточка. rank с 1.
GET/jobs/{id}/variants/{rank}/geojsonGeoJSON одного варианта, файл heatnet-{id}-v{rank}.geojson.
GET/jobs/{id}/result.geojsonВсе варианты, файл сдачи heatnet-{id}-result.geojson.

Тело POST /jobs:

ПолеСмысл
datasetIdОбязателен. UUID набора.
modePLAN_2D или DEPTH. По умолчанию PLAN_2D. Режимы ранжируются отдельно.
strategiesСписок: mincost — минимальная стоимость, mintaps — минимум врезок, minrecon — короче трасса. Пустой список или отсутствие поля — все три.

status задачи: QUEUED — в очереди, RUNNING — считаю, COMPLETED — готово, FAILED — ошибка. Поля: id, datasetId, mode, status, progress, message, error, createdAt, startedAt, finishedAt.

Карточка варианта

ПолеСмысл
rankМесто. 1 — наименьший S.
title, code, descriptionПодпись режима. Коды те же, что в strategies.
costРасчётная стоимость C, ₽: трубы + новые камеры + врезки в существующие камеры + штраф.
lengthMДлина новой сети, м. Реконструкция в длину не входит.
reconLengthMВ текущем расчёте всегда 0.
scoreS = 0,7·C / 25 000 000 + 0,3·L / 100.
unconnectedCount, unconnectedIdsОКС, до которых маршрут не дошёл.
breakdownpipe_cost, chamber_construction_cost, existing_chamber_tie_in_cost, existing_chamber_tie_in_count, unconnected_penalty, construction_cost, calculated_cost. Поля reconstruction_cost и chamber_reconstruction_cost равны 0.
notesКороткие пояснения расчёта.

GeoJSON результата

Один FeatureCollection, имя heatnet-result, геометрия WGS 84. Координата Z не пишется. Объекты: heat_network, heat_chamber, technical_node, variant_summary. variant_id — строка "1", "2" или "3".

ТипПоля
heat_networkstart_node_id, end_node_id, flow_tph, diameter, length, laying_method (base или special), depth_start, depth_end, cost. Длина — горизонтальная проекция. В режиме PLAN_2D обе глубины равны null. В режиме DEPTH это глубина до верха габарита, четыре знака.
heat_chamberНовая камера: diameter, cost. Стоимость уже включает присоединение.
technical_nodeСтык участков. Стоимости нет.
variant_summaryГеометрии нет. rank, construction_cost, chamber_construction_cost, existing_chamber_tie_in_count, existing_chamber_tie_in_cost, unconnected_penalty, calculated_cost, new_network_length, score, unconnected_oks_ids.

Врезка в существующую камеру — 5 000 000 ₽ за каждый новый участок, который в ней заканчивается. Сумма лежит в сводке, отдельного объекта врезки нет.

Таблицы

МетодПутьСмысл
GET/appendixТаблицы DN, стоимости, ограничений, рейтинга и глубины, JSON. Файл перечитывается при каждом запросе.
GET/appendix/rawТот же файл, YAML. Если файла по пути нет — текст, что взят classpath default.yml.
GET/appendix/metaappendixPath, storageDir, maxUploadBytes, async.

В JSON остаются рабочие поля. Глубина: min_depth_m 0,7, default_depth_m 3,0, cost_factor_per_m_depth 0,10, max_slope 0,10. Стоимость: tap_in_pipe, tap_in_chamber, unconnected_fixed, unconnected_per_tph, new_chamber_tiers. Цена метра трубы — new_per_m в таблице DN. Вертикальные просветы раздела 5 заданы в коде режима DEPTH. recon_per_m в смете не применяется. along-road-penalty и extra_grid_cost в рубли не переводятся.

Прогон без браузера

МетодПутьСмысл
POST/demo/run?mode=PLAN_2DСчитает встроенный мини-набор. mode: PLAN_2D или DEPTH.
POST/demo/contest?mode=PLAN_2DСчитает конкурсный файл, если он есть на сервере. Тот же параметр mode.

Офлайн, без HTTP: java -jar target/heatnet.jar --process-contest --mode PLAN_2D --out samples/contest-result.geojson. Для глубины --mode DEPTH. То же самое делает make contest в плоском режиме.
